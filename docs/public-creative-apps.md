# 公共创作：管理员发布，客户直接生成

公共创作适用于商品海报、参考图生图、图片转视频等固定流程。管理员维护媒体工作流和模型，客户只填写开放的参数，不需要搭建画布。

| 入口 | 用途 | 修改与数据归属 |
| --- | --- | --- |
| 我的工作流 | 用户自己搭建和运行 | 私有工作流，原有行为不变 |
| 模板 | 复制后继续编辑 | 实例化为用户自己的工作流 |
| 公共创作 | 使用管理员发布的固定应用 | 图和模型由管理员维护，每次输入、任务和生成素材归调用账户 |
| 外部 API | 系统集成 | 沿用 API Key、REST/SSE、AG-UI；与公共创作的发布版本独立 |

## 发布与使用

1. 管理员在 **工作流中心 → 媒体创作** 创建并调试流程。
2. 在画布字段旁点击 **API**，绑定客户可填写的提示词、参考图、比例、质量、数量、时长等参数，设置名称、必填、默认值及范围。声明需要交付的图片或视频输出。
3. 进入详情 **发布与版本 → 公共创作**，配置名称、说明、图片/视频分类、可选封面、并发上限和每日额度。
4. 若流程含固定参考图，必须明确勾选共享授权。必填图片参数会移除草稿里的示例图片，客户漏传时不会使用管理员的样例。
5. 确认发布后生成不可变版本。普通客户登录网页 `/creative-apps`，或桌面客户端 **公共创作**，选择应用、填写参数并生成。
6. 输入图片支持本地上传和素材库复用。提交立即返回任务；离开页面、关闭客户端不会取消服务器已受理的任务。客户可在 **我的任务** 查看进度、预览、下载或取消任务。

下架只停止新提交，已经受理的任务继续使用原版本，历史结果仍可查看。管理员可切换历史版本；重新启用时检查模型和固定素材是否可用。删除工作流前必须下架公共创作，同时遵循原有 API、模板及活动任务引用检查。

## 发布契约与模型

- 支持 `text`、`image`、`imageGenerate`、`videoGenerate`、`imageOutput`、`videoOutput`、`output` 媒体节点；至少有一个生成节点，并声明图片或视频结果。
- 通用编排、视频续接和抽帧节点不在公共创作的发布节点集合中；原入口仍按各自规则使用。
- 参数类型为 `string`、`integer`、`boolean`、`enum`、`image`，验证沿用媒体工作流的参数契约。模型、渠道和内部节点绑定不对客户开放。
- 发布时将默认角色解析为具体模型。每次提交和实际执行仍检查模型启用状态；修改后台默认角色不会替换已发布版本的模型。调整模型应发布新版本。渠道的地址和密钥仍由后台统一管理。
- Seedream 原生图片模型保留其分辨率、提示词优化选项；OpenAI 图片模型保留质量选项。发布时拒绝当前协议不支持的参数，避免混用。
- 固定参考图必须是发布工作流所属账户的可用素材。共享后仅为这次客户任务创建素材元数据副本，复用同一文件，不开放发布者的素材列表。

## 任务、限制与恢复

| 限制 | 默认 | 可配置范围 |
| --- | --- | --- |
| 应用并发 | 2 | 1–32 |
| 每用户在该应用的并发 | 1 | 1–8 |
| 每用户在该应用的每日提交额度 | 50 | 1–10000 |
| 单应用排队上限 | 100 | 固定 |
| 每账户跨公共应用的活动任务上限 | 20 | 固定 |

每日额度以 **UTC 零点** 重置，计入已经受理的任务，包括之后失败或取消的任务；同一幂等请求的重放不占新额度。并发准入在数据库事务中复核，多 Worker 不能越过应用/用户并发上限。公共任务继续走现有 MAF 执行器和媒体服务的调度规则。

每次新生成使用新的 `requestKey`。相同账户、应用、请求键、版本和参数只对应一个任务；同键不同内容返回 `409`。客户端保存待确认请求标识，网络中断或服务器错误后先查询，**不自动重发生成 POST**。刷新页面后的历史查询、重新查询结果和重新下载不会发起新模型调用；点击重新生成才创建新任务。

这些限制是任务额度，不是积分或在线支付计费。模型费用仍按实例已有的服务商配置承担。取消已提交上游的任务无法保证撤销上游处理或费用。服务进程中断后的失败/结果不明沿用现有执行器恢复规则，不自动再次生成。

## 客户接口

客户使用普通账户会话和设备握手访问自己的任务和素材。表单字段、任务状态、历史成品和调用示例见[公共创作前端对接](creative-apps-frontend.md)。

## 管理接口与数据库

管理入口为 `/api/v1/admin/workflow-apis/{id}/creative-app`，需要管理员身份及对应后台工作流范围：GET 读取、PUT 发布、DELETE 下架，POST `/versions/{releaseId}/activate` 切换版本。沿用后台工作流管理入口的启用条件，不通过普通用户接口发布。

迁移 `0049__creative_apps.sql` 新增应用、版本、任务关联与发布审计表，扩展 `workflow_run.trigger_type`，把发布素材接入现有引用保护。旧迁移和校验文件未改写，不删除或重建既有工作流/素材。按[部署指南](deployment.md#4-apply-migrations-once)先执行迁移，再部署匹配的后端和客户端。

## 验证范围

自动化使用隔离 PostgreSQL schema、合成图片/视频上游，覆盖真实 HTTP、MAF Worker、版本、幂等、客户权限、固定素材共享、限额、并发和媒体 Range。网页组件与浏览器使用合成数据验证表单和任务交互。桌面原生测试覆盖会话 Cookie、接口允许列表、视频范围读取及下载中断保护。这些验证不代表已经测试每个实际模型的生成效果。
